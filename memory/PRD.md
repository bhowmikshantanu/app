# AmbaShree Skills Academy & Institute — PRD

## Original Problem Statement
Create a premium, modern, fully responsive website for AmbaShree Skills Academy & Institute with sections: Hero, Courses, Why Choose Us, Faculty, Gallery, Testimonials, Contact, Footer. Theme: Blue + Gold, glassmorphism, smooth animations, SEO optimized.

## User Choices
- Contact: placeholder values (user will update)
- Contact form: show success message only (no DB storage)
- Social links: placeholder (#)
- Branding: text logo with "A" + "Sa" initials

## Architecture
- Frontend-only React SPA (no backend routes needed for this feature)
- Single Home page with anchored sections
- Sonner for toast notifications
- No 3rd-party integrations required

## Implemented (2026-Q1)
- Header (sticky, glass on scroll, mobile drawer)
- Hero (image bg, gradient overlay, marquee pills, stats, 3 CTAs including WhatsApp)
- Courses (10 course cards, hover reveal)
- Why Choose Us (bento layout, 6 features)
- Faculty (3 detailed profile cards with credentials)
- Gallery (staggered/masonry grid with placeholder-replace UI)
- Testimonials (carousel with dots + autoplay)
- Contact (form validation + info cards + embedded Google Maps)
- Footer (4-column with brand, links, courses, contact)
- Floating WhatsApp button
- SEO meta tags + premium fonts (Cormorant Garamond + Outfit)
